# 麦麦积分清仓官

把「我的麦麦积分」这件没人提醒的事做成一次点击。

## 何时使用

- 「我的麦麦积分还有多少」「有没有积分快过期了」
- 「这些积分能换什么」「换哪个最划算」
- 「帮我生成一张积分体检卡」
- 「把快过期的积分用掉」

## 工作流

1. 调 `query-my-account`，取出 `availablePoints` 与 `expiringPoints`。
   - `expiringPoints > 0` → 进入清仓模式，推荐池 = `expiringPoints`
   - `expiringPoints == 0` → 进入常规模式，推荐池 = `availablePoints`
2. 调 `mall-points-products` 拉取可兑换商品，按积分价升序排列。
3. 输出三类结论：
   - **过期前还换得起**：`points <= 推荐池`
   - **最优解**：上述集合中积分价最高的那件（最大化消耗临期积分）
   - **再攒一点点**：超过推荐池、按差额升序取前 5
4. 用户确认后调 `mall-create-order` 下单；若用户只是想看看，生成体检卡即可，不要擅自下单。

## 输出格式

命令行或对话中输出体检报告：

```
可用积分      : 2480
即将过期积分  : 900   <-- 有清仓风险!
过期前可兑 (900 分内):
  - 麦旋风兑换券        400 分
  - 中薯条兑换券        500 分
  - 板烧鸡腿堡兑换券    900 分
最优解: 板烧鸡腿堡兑换券 (900 分)
```

## 注意事项

- **未得到用户明确确认前，绝不调用 `mall-create-order`**，积分兑换不可逆。
- Token 只从环境变量 `MCD_MCP_TOKEN` 读取，不要写进任何文件。
- 单次体检的 MCP 调用控制在 5 次以内，避免触发 600 次/分钟限流。
- 餐品与商品以官方实时结果为准，输出仅供参考。
